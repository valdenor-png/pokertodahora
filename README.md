# pokertodahora

Portal de notícias, estratégias e bastidores do poker — "Notícias, estratégias e bastidores para você jogar mais e melhor".

Site estático em um único arquivo (`index.html`) com HTML, CSS e JavaScript, mais as imagens em `img/` (`logo.webp` usado no site, `og-image.jpg` para a prévia ao compartilhar e `logo.jpg` como arquivo original).

## Como ver localmente

Abra o `index.html` no navegador.

## Deploy

Publicado na Vercel como site estático (sem build).
